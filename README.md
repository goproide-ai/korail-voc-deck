# 통합 앱 코레일+ 예약 과정 UX/UI VOC 인사이트 보고서

제2차 공공누리집 UI/UX 위원회 의견제출서 별첨 자료입니다. 29장 발표자료 한 파일로 되어 있습니다.

- 작성: 서울과학기술대학교 디자인학과 고성찬 교수
- 조사 기간: 2026년 8월 3일 앱 출시 이후 ~ 9월 6일
- 검토 범위: 열차 조회 · 예약 · 예약 변경 · 결제 · 결제 취소 등

## 파일 구성

```
index.html          발표자료 본문 (29장)
support.js          렌더링 런타임
deck-stage.js       슬라이드 진행·인쇄 컴포넌트
assets/             자체 점검 프로그램 실행 화면 캡처 4개
vercel.json         정적 배포 설정
```

## 로컬에서 보기

브라우저로 `index.html`을 열면 됩니다. 스크롤·클릭·방향키로 넘기고, 하단 썸네일에서 원하는 장으로 이동할 수 있습니다.

## 배포

정적 파일이라 빌드 과정이 없습니다.

- Vercel: 프레임워크 Other, 빌드 명령 없음, 루트 그대로 배포
- GitHub Pages: 저장소에 올린 뒤 Pages에서 브랜치와 루트 지정
